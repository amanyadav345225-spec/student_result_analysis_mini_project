# Student Result Analysis 📊

This project analyzes student academic performance using Python, NumPy, Pandas, Matplotlib, and Seaborn.

The project focuses on data cleaning, statistical analysis, student performance analysis, and data visualization.

---

## 📌 Project Overview

The main objective of this project is to analyze students' marks in different subjects and extract useful information from the dataset.

The analysis includes:

- Total marks calculation
- Percentage calculation
- Pass/Fail analysis
- Highest and lowest marks
- Subject-wise performance analysis
- Average marks by subject
- Maximum marks by subject
- Percentage distribution
- Subject-wise marks distribution
- Correlation analysis

---

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab
- Git & GitHub
